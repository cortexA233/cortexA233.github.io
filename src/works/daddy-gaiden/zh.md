一款受《忍者龙剑传 2》与《Hades》启发的 2D 动作 Roguelike 原型，试图在 2D 横版动作的框架下
实现类似“高速动作游戏”的战斗体验，并融入 Rogue-like 元素增加可玩性。在 game jam
期间完成，我担任**主创、战斗设计与主程序**。

- 设计了整套战斗机制，并配套资源管理系统，让每一局循环更充实、更爽快；
- 实现了游戏的全部功能，并着重打磨战斗手感；
- 自主管理项目：制定任务表与排期，协调各参与者，在 game jam 周期内顺利完成。

## 游玩信息

参加 Beginners' Jam Winter 2025/6。itch.io 标记为开发中，提供浏览器、Windows 和 macOS 版本；项目页推荐下载版。

在高速战斗中斩击水果并生存下来：WASD 移动，鼠标左键 / J 攻击，鼠标右键 / K 进入 Boost 模式，Shift 格挡，空格闪避。
