**汪孟翔（Mengxiang Wang / cortexA233）**<br>
**游戏玩法/系统程序员**

我使用 C++ 和 C# 开发玩法系统、相机与编辑器工具。曾在**网易游戏**的《遗忘之海》中负责相机平台、战斗与移动同步及策划工具，在**叠纸游戏**的《闪耀暖暖》中开发空间查询与拍照模式相关系统。

独立游戏 **Exp10sion** 中，我担任主程序、项目管理与关卡设计，参与将游戏发布到 Steam 与 Nintendo Switch。我也搭建了后续项目复用的 Unity 游戏逻辑框架 [KToolkit](https://github.com/cortexA233/KToolkit_for_unity)，并持续通过游戏原型探索动作手感与玩法机制。

目前在美国波士顿的**东北大学（Northeastern University）**攻读游戏科学与设计硕士（2025–2027）；本科毕业于**上海大学**通信工程（Electronic Engineering）专业。

自 2025 年 7 月起，我在 **Philo Labs** 担任软件开发工程师实习生，面向游戏引擎与 3D 工作流开发智能体评测和自动化测试工具。这段经历也让我积累了 AI 辅助开发、跨引擎验收与可复现回归测试方面的经验。

**技术栈** —— C++、C#、Python、Lua · Unity、Unreal Engine、Godot、Messiah · Qt/PyQt、IMGUI、Git。使用 Codex、Claude Code 和 MCP 辅助开发与测试。

**语言** —— 中文（母语）、英语（TOEFL iBT 102）、日语（JLPT N1）。
