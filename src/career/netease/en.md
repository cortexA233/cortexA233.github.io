At **NetEase Games, Joker Studio**, I developed systems and tools for **Sea of Remnants** using C++, Python, PyQt, and the in-house **Messiah** engine.

**Period:** November 2023 – May 2025<br>
**Technologies:** C++, Python, PyQt, Messiah

## Game-wide camera platform

- Owned the design, implementation, and maintenance of the game's camera platform.
- Standardized APIs across pipelines and node graphs.
- Added collision handling, inertia, debug controls, and reusable camera modifiers for designers.

## Real-time combat and networking

- Developed real-time client/server combat and movement replication.
- Optimized data serialization and network protocols, reducing **peak traffic by 97.5% (4 MB to 100 KB)** and supporting a stable, high-concurrency alpha release.

## Authoring and debugging tools

- Built **PyQt and IMGUI** tools for authoring and debugging combat, cinematics, and character lighting.
- Added keyframes, event nodes, frame events, and scripting APIs for designers.
