シニアゲーム開発エンジニア — NetEase Games

2023-11-01 · C++ Python PyQt Messiah

NetEase Games の Joker Studio で、C++、Python、PyQt と自社エンジン Messiah を使用し、Sea of Remnants のシステムと開発ツールを担当しました。

在籍期間： 2023 年 11 月 – 2025 年 5 月
使用技術： C++、Python、PyQt、Messiah

ゲーム全体のカメラ基盤

  • ゲーム全体で使用するカメラ基盤の設計・実装・保守を担当。
  • 各パイプラインとノードグラフで利用する API を標準化。
  • 衝突処理、慣性、デバッグ操作、プランナーが再利用できるカメラ修飾子を追加しました。

リアルタイム戦闘とネットワーク同期

  • クライアント／サーバー間のリアルタイム戦闘と移動同期を開発。
  • データシリアライズと通信プロトコルを最適化し、ピーク時の通信量を 4 MB から 100 KB へ、97.5% 削減。高同時接続のアルファ版の安定稼働を支えました。

編集・デバッグツール

  • 戦闘、シネマティクス、キャラクターライティングの編集とデバッグを行う PyQt／IMGUI ツールを構築。
  • プランナー向けにキーフレーム、イベントノード、フレームイベント、スクリプト API を追加しました。
