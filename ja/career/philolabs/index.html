ソフトウェア開発エンジニア（インターン）— Philo Labs

2025-07-01 · Python Three.js RAG Unity Unreal Engine Godot C++ C#

米国サンフランシスコの Philo Labs で、AI エージェントのソフトウェア開発能力の評価と、ゲームエンジンや Web フレームワークを対象とした再現可能なテストツールの開発に携わっています。

在籍期間： 2025 年 7 月 – 現在
使用技術： Python、Three.js、RAG、Unity、Unreal Engine、Godot、C++、C#

エージェントによるソフトウェア開発のベンチマーク

  • Phaser、Three.js、Unity、Godot を対象に、開発能力のベンチマークと自動受け入れテストを設計。
  • 製品仕様を、正確性、操作へのフィードバック、ビジュアル表現、安定性について採点可能な評価基準へ落とし込みました。

3D ワークフローと再現可能な評価

  • エージェントが生成する 3D アセットとシーンを対象に RAG ワークフローを構築。
  • Skills と Evals を作成し、Unity と Godot の MCP サーバーを統合。成果物の自動収集と、モデル間で再現可能な回帰テストを実現しました。
